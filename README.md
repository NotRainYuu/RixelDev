## 🚀 Quick Execution

Run the official script in your executor (compatible with Wave, Solara, Delta, Synapse Z, AWP, etc.):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/NotRainYuu/RixelDev/main/loader.lua"))()
```

Alternative direct endpoint:
```lua
loadstring(game:HttpGet("https://rixeldev.lol/loader"))()
```
